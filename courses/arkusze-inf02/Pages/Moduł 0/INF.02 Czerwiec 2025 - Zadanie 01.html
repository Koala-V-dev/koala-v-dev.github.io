INF.02 — Czerwiec 2025 (Zadanie 01: Sieć LAN, Windows Server i Ubuntu)

Poniżej znajdziesz oficjalne materiały do arkusza praktycznego kwalifikacji INF.02 z podziałem na wymagane środowiska systemowe oraz źródło pochodzenia arkusza.

📌 Ważny punkt

Oryginały jawnych arkuszy egzaminacyjnych pochodzą bezpośrednio z zasobów Centralnej Komisji Egzaminacyjnej (CKE) oraz Okręgowych Komisji Egzaminacyjnych: cke.gov.pl/egzamin‑zawodowy.

Wymagane środowiska i zakres zadań

  • System serwerowy: Windows Server (Active Directory, DNS, DHCP, udziały sieciowe)
  • System kliencki: Ubuntu Desktop / Windows 11 (konfiguracja interfejsu sieciowego, diagnostyka ip a, ping, nslookup)
  • Urządzenia sieciowe: konfiguracja routera i przełącznika (VLAN, brama domyślna, okablowanie)

Lista kontrolna przed oddaniem stanowiska

  • Zweryfikuj adresację IP, maskę podsieci i bramę domyślną na wszystkich interfejsach.
  • Sprawdź łączność w sieci lokalnej oraz rozwiązywanie nazw DNS.
  • Upewnij się, że wszystkie zrzuty ekranu dokumentujące konfigurację zostały zapisane w folderze wynikowym zgodnie z instrukcją arkusza.
