Maski Bitowe i Operacje Niskopoziomowe

W zadaniach egzaminacyjnych kwalifikacji INF.02 (administracja systemami i sieciami) oraz INF.03/INF.04 (programowanie) operacje bitowe pojawiają się w dwóch kluczowych momentach:

  1. Adresowanie IPv4 i maski podsieci (np. wyznaczanie adresu sieci za pomocą operacji bitowej `AND`).
  2. Uprawnienia do plików w systemie Linux (polecenie `chmod` i maska praw `rwx`).

🎯 Czym jest maska bitowa?

Maska bitowa to wzorzec bitów (ciąg zer i jedynek), który przykładamy do innej liczby za pomocą operacji logicznej (`AND`, `OR`, `XOR`), aby:

  • Wyciąć (przefiltrować) interesujące nas bity,
  • Włączyć określony parametr (ustawić bit na $1$),
  • Wyłączyć parametr (zgasić bit na $0$),
  • Sprawdzić czy dana flaga jest aktywna.

🌐 Maska bitowa w praktyce egzaminu INF.02: Obliczanie adresu sieci

W sieciach komputerowych IPv4 każdy adres IP i maska to w rzeczywistości 32 bity (4 oktety po 8 bitów).

Gdy komputer chce dowiedzieć się, w jakiej sieci się znajduje, wykonuje bitową operację koniunkcji (`AND`) między adresem IP a maską podsieci:

Element Zapis dziesiętny Zapis binarny (jeden oktet)
Adres IP komputera `192.168.1.77` `... . 0100 1101` ($77$)
Maska podsieci `255.255.255.240` `... . 1111 0000` ($240$)
Operacja bitowa AND Adres sieci `... . 0100 0000` ($64$)

Bramka `AND` przepuszcza tylko te bity, gdzie w masce była jedynka. Tam, gdzie w masce są zera (część hosta), bity adresu IP zostają wyzerowane. Wynik to adres podsieci: `192.168.1.64`.

🐧 Maski bitowe w uprawnieniach Linux (chmod i POSIX)

W systemie Linux uprawnienia pliku zapisywane są w trzech triadach bitowych: odczyt ($r=4$), zapis ($w=2$) i wykonanie ($x=1$):

Gdy wpisujesz `chmod 754 plik`:

  • `7` ($4+2+1$) $\to$ `111` (właściciel: pełne prawa `rwx`),
  • `5` ($4+0+1$) $\to$ `101` (grupa: odczyt i wykonanie `r‑x`),
  • `4` ($4+0+0$) $\to$ `100` (pozostali: tylko odczyt `r--`).

⚙️ Cztery podstawowe operacje na flagach w programowaniu

W kodzie programistycznym (C++, C#, JavaScript) zamiast tworzyć dziesiątki osobnych zmiennych logicznych `bool`, pakujemy je do jednego bajtu lub liczby całkowitej za pomocą 4 reguł:

  1. Włączenie flagi (SET) – bramka `OR` (`|`):
    ```cpp
    flagi |= 0x02; // Wymusza 1 na danej pozycji bez ruszania pozostałych
    ```
  2. Wyłączenie flagi (CLEAR) – bramka `AND` z negacją (`& ~`):
    ```cpp
    flagi &= ~0x02; // Gasi wybrany bit do 0
    ```
  3. Przełączenie flagi (TOGGLE) – bramka `XOR` (`^`):
    ```cpp
    flagi ^= 0x02; // Zmienia 0 na 1 lub 1 na 0
    ```
  4. Sprawdzenie flagi (TEST) – bramka `AND` (`&`):
    ```cpp
    if ((flagi & 0x02) != 0) {
    // Flaga jest włączona!
    }
    ```
🔬 Pod maską: Bit Twiddling Hacks i programowanie bezrozgałęzieniowe (Branchless) C++ & WYDAJNOŚĆ ALU

Dla inżynierów i programistów silników gier oraz baz danych kluczowa jest eliminacja instrukcji skoków warunkowych (`if/else`), które powodują czyszczenie potoku wykonawczego procesora (Branch Misprediction Penalty rzędu 15‑20 cykli zegara).

1. Izolacja najmłodszej jedynki: \`x & (-x)\`

Dzięki właściwościom kodu U2 (gdzie $-x = \\neg x + 1$), operacja ta gasi wszystkie bity poza najmłodszą jedynką:
```cpp
uint32_t lowestBit = x & (-x); // Np. dla 0010 1100 (44) daje 0000 0100 (4)
```

2. Test potęgi dwójki w 1 cyklu zegara: \`(x & (x - 1)) == 0\`

Liczba będąca potęgą dwójki ma w zapisie binarnym dokładnie jedną jedynkę. Odjęcie 1 zamienia tę jedynkę na zero i zapala bity po prawej stronie. Koniunkcja z `x` daje zero:
```cpp
bool isPowerOfTwo = (x > 0) && ((x & (x - 1)) == 0);
```

3. Wartość bezwzględna bez rozgałęzienia (Branchless ABS)

```cpp
int32_t branchless_abs(int32_t x) {
int32_t mask = x >> 31; // 0 dla x >= 0 lub -1 (0xFFFFFFFF) dla x < 0
return (x + mask) ^ mask;
}
```

4. Atomowa modyfikacja rejestrów w mikrokontrolerach ARM

W mikrokontrolerach STM32 (ARM Cortex‑M) do sterowania pinami procesora stosuje się rejestry atomowe `BSRR` (Bit Set/Reset Register) lub sprzętowy mechanizm Bit‑Banding, eliminujący błędy wyścigu przy przerwaniach bez konieczności blokowania magistrali.

🔒 Weryfikacja: Maski bitowe

🦾🐨🦾 Co masz wynieść z tej lekcji:

  • Maska bitowa to wzorzec używany do izolowania, włączania lub wyłączania określonych bitów.
  • W kwalifikacji INF.02 maska służy m.in. do wyznaczania adresu sieci z adresu IP za pomocą operacji bitowej `AND`.
  • Uprawnienia uniksowe `chmod` bazują na 3‑bitowych maskach praw `rwx` zapisywanych cyframi ósemkowymi ($4, 2, 1$).
  • Cztery kanoniczne operacje na flagach w programowaniu to SET (`|=`), CLEAR (`&= ~`), TOGGLE (`^=`) i TEST (`&`).
